# Eval di grl-automation

I casi verificano classificazione, routing, idempotenza, read-only, dry-run, separazione delle
approvazioni e gestione dei domini legale, fiscale, design, architettura, medicina, software,
database e paid media. Coprono anche diagnosi falsificabile e passaggi human-only per cutover.
Il workflow non deve trasformare una richiesta generica di automazione in un'azione esterna non
autorizzata.
