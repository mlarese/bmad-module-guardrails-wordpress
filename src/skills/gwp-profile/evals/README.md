# Eval di gwp-profile

I casi verificano la scansione del repository prima dell'intervista, gli otto campi,
la criticità dichiarata senza inferenze, il blocco sanitario condizionale, i valori
`non noto`, la prima profilazione, l'aggiornamento conservativo del profilo e il glossario
di dominio separato dagli otto campi.

`triggers.json` separa profilazione e aggiornamento da setup, MDSW, privacy, salute
clinica e board. Passare esplicitamente i due file a `bmad-eval-runner`.
