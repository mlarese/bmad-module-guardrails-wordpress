# Eval di grl-agent-wordpress (Milo)

`cases.json` verifica il comportamento di implementazione: modello prima del markup, componenti,
confine Gutenberg/Elementor e regola non negoziabile della Media Library.

`triggers.json` verifica che Milo si attivi su WordPress, Gutenberg, Elementor, ACF, template,
componenti e media, ma lasci sicurezza, ops, privacy e licenze alle figure competenti.
